# CurveQz

เว็บไซต์แนะนำโครงงาน **CurveQz** — ระบบช่วยร้านอาหารวางแผนสั่งวัตถุดิบให้ใกล้เคียงกับยอดขายจริง
เพื่อลดวัตถุดิบที่ต้องทิ้ง และลดเวลาที่ผู้จัดการสาขาต้องนั่งคำนวณเอง

โครงงานรายวิชาของนักศึกษา สถาบันการจัดการปัญญาภิวัฒน์ (PIM)

🔗 <https://curveqz.github.io/CurveQz.github.i/>

## สถานะปัจจุบัน

หน้าเว็บนี้เป็นการนำเสนอ **แนวคิดและขอบเขตของโครงงาน** ยังไม่ใช่ระบบที่ใช้งานได้จริง
กราฟและตัวอย่างสูตรอาหารบนหน้าเว็บวาดขึ้นเพื่ออธิบายแนวคิด ยังไม่ได้มาจากข้อมูลของร้านจริง

## โครงสร้างไฟล์

```
index.html              โครงหน้าเว็บ (ข้อความหลักของแต่ละ section)
js/
  theme.js              ธีมมืด/สว่าง (โหลดใน <head> ก่อนไฟล์อื่น)
  data.js               ข้อมูลที่แก้บ่อย: สมาชิกทีม (TEAM) และเมนูตัวอย่าง (MENUS)
  main.js               smooth scroll + สร้างตารางทีม/ตารางวัตถุดิบจาก data.js
css/
  variables.css         สีทั้งหมดของเว็บ ทั้งธีมสว่างและมืด (ต้องโหลดเป็นไฟล์แรก)
  base.css              reset, ฟอนต์, container
  navbar.css            แถบเมนูด้านบน
  hero.css              ส่วนหัวและกราฟประกอบ
  sections.css          เลย์เอาต์ของแต่ละ section
  tables.css            ตารางเปรียบเทียบ ตารางวัตถุดิบ ตารางทีม
  footer.css            ส่วนท้าย + ไอคอน GitHub
  responsive.css        media queries (ต้องโหลดเป็นไฟล์สุดท้าย)
assets/
  brand/                โลโก้และ favicon
  icons/                ไอคอน SVG
  team/                 รูปสมาชิกทีม
```

## อยากแก้อะไร แก้ที่ไหน

| อยากแก้ | ไฟล์ |
|---|---|
| เพิ่ม/ลบ/แก้ข้อมูลสมาชิกทีม | `js/data.js` → `TEAM` |
| เพิ่มเมนูหรือวัตถุดิบในตารางตัวอย่าง | `js/data.js` → `MENUS` (ปุ่มเมนูสร้างให้เอง) |
| ข้อความในแต่ละ section | `index.html` |
| สีของทั้งเว็บ | `css/variables.css` (แก้ให้ครบทั้งบล็อกสว่างและมืด) |
| ขนาดตัวอักษร ระยะห่าง | ไฟล์ CSS ของ section นั้นๆ |
| หน้าตาบนมือถือ | `css/responsive.css` |

**เพิ่มสมาชิกทีม:** ใส่รูปสี่เหลี่ยมจัตุรัส (~400px, .jpg) ใน `assets/team/`
แล้วเพิ่ม object ใหม่ใน `TEAM` ตามแบบของคนอื่น

## ธีมมืด/สว่าง

- เปิดครั้งแรกใช้ธีมตามที่เครื่องตั้งไว้ กดปุ่มพระจันทร์/พระอาทิตย์ในแถบเมนูเพื่อสลับ แล้วเว็บจะจำไว้
- สีทุกสีต้องมาจากตัวแปรใน `css/variables.css` **ห้ามเขียนสีตรงๆ เช่น `#3A694A`** ในไฟล์อื่น
  ไม่งั้นสีนั้นจะไม่เปลี่ยนตอนเป็นธีมมืด
- ธีมมืดใช้หลักของ [Material Design 3](https://m3.material.io/styles/color/roles) คำนวณจาก tonal palette ของสีเขียวแบรนด์
  (พื้น tone 6, กล่องซ้อน tone 10–17, ตัวอักษร tone 90/80, สีเน้น tone 80) ดูรายละเอียดในคอมเมนต์ของ `css/variables.css`
- ชื่อตัวแปรบอกหน้าที่ เช่น `--surface` (พื้นหลัง), `--text-strong` (หัวข้อ), `--accent` (สีเน้น)
- เพิ่มสีใหม่ต้องใส่ทั้งใน `:root` และ `:root[data-theme="dark"]`
- สีตัวอักษรทุกคู่ผ่านเกณฑ์ WCAG AA (contrast อย่างน้อย 4.5:1) ทั้งสองธีม ถ้าเปลี่ยนสี ลองเช็คที่ <https://webaim.org/resources/contrastchecker/>

**ห้ามใส่ `style="..."` ใน HTML** — ให้สร้าง class ในไฟล์ CSS แทน
จะได้แก้ดีไซน์ที่เดียว

## การพัฒนา

ไม่มี build step — เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย
หรือรันเซิร์ฟเวอร์ในเครื่องเพื่อให้ path ของไฟล์ทำงานถูกต้อง

```bash
python -m http.server 8000
```
